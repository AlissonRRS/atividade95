# Meu Primeiro Projeto

## Sobre o projeto

Este é meu primeiro projeto desenvolvido para a disciplina, com o objetivo de aprender a utilizar o GitHub e praticar a criação e organização de arquivos em um repositório.

## Tecnologias utilizadas

- HTML
- GitHub

## Estrutura do projeto

- `HelloWorld.html` — página HTML inicial do projeto.
- `README.md` — documentação do projeto.

## Objetivo

O objetivo deste projeto é aprender conceitos básicos de desenvolvimento web e também como criar, organizar e publicar um projeto utilizando o GitHub.
